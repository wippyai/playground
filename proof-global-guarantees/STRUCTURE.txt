ARCHITECTURE VALIDATED:
  - Sharding: FNV-1a consistent hashing
  - Consensus: Raft per shard
  - Cross-shard: 2PC (Two-Phase Commit)
  - Gossip: Cluster membership and failure detection
  - Reads: Lock-free via sync.Map + atomics

USAGE:
  cd proof-global-guarantees
  wippy run src/runner.lua              # Run all 6 proof tests
  wippy run src/test/proof/ultimate_global_guarantee.lua  # Run specific test
